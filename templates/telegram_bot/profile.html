📖 Como configurar

1. Abra o @BotFather no Telegram
2. Crie um bot com /newbot
3. Copie o token gerado
4. Cole aqui acima e salve

💡 Dicas

  • O Chat ID pode ser obtido enviando /start para o bot e acessando a API (ex: https://api.telegram.org/bot<TOKEN>/getUpdates)
  • Você também pode usar o bot @get_id_bot para obter seu chat id
  • Notificações serão enviadas automaticamente ao emitir notas
  • Você pode desativar a qualquer momento
